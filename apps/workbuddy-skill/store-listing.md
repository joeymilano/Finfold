# 商店上架物料 · Finfold 获客搭子

提交审核时逐项复制。文案定稿前过一遍 human-writing 标准（真人味，禁营销腔）。

## 基本信息

- **名称**：Finfold 获客搭子
- **简介**：把产品介绍变成客户用得上的互动自测和个性化清单，配好推广文案与咨询入口。

## 详细介绍

已经在发内容，却不知道如何让客户迈出下一步？把你的网站、产品介绍或服务材料交给 Finfold 获客搭子，生成一个带有你自己品牌的客户小工具：来访者答五道题，拿到一份对应的行动清单，最后自然走到你的咨询或服务入口。

先预览、修改，再决定是否发布；不用先写提示词，也不用从零设计页面。生成的是单个 HTML 文件，双击就能用，发到微信、挂到公众号菜单都行；想看有多少人打开、做完、点了你的入口，可以把工具搬进 Finfold 托管。

## 首次使用提示（给用户的开场白）

> 这是我的产品或服务介绍：〔粘贴你的介绍〕
> 请帮我做一个对潜在客户真正有用的小工具，不要硬广，先给我完整预览。

## 展示图规划（三张）

1. **主图 · 前后对比**：左边一段普通的产品介绍文字，右边一个客户真的能点、能得到结果的成品工具截图（问句标题 + 选项按钮可见）。图上标注「演示数据」。
2. **第二张 · 四件套**：一张图讲清交付物——工具 + 推广文案 + 咨询入口 + 效果数字，各占一角，用真样例截图拼。
3. **第三张 · 数据回流**：Finfold 数据页截图（打开/完成/入口点击漏斗 + 咨询结果三档），说明「托管后能看到什么」。

三张图统一用真样例（Finfold 自用样例 + 设计服务样例 + 小团队样例），来源是部署后创建的三个真实工具页。

## 审核备注（如实披露）

- 技能本身免费（Finfold 不收取基础功能费用）；任务执行消耗 WorkBuddy 平台自身积分，与 Finfold 无关
- 生成的工具为本地单文件 HTML，不上传、不联网；唯一外链是工具主人自己的咨询入口
- 对 Finfold 托管服务的引导仅在用户主动表达「想看数据/想托管/想继续迭代」时出现，一次性、可忽略
- 隐私边界：来访者匿名作答，不注册、不留联系方式、答案不出浏览器
