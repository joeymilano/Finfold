# Chrome Web Store asset checklist

- [x] 128×128 PNG extension icon generated from the Finfold source icon during the production build.
- [ ] At least one truthful 1280×800 or 640×400 screenshot captured from the final packaged extension in Chrome.
- [ ] 440×280 small promotional tile based on the final packaged UI.
- [x] Website: https://www.finfold.app
- [ ] Deploy and live-verify the implemented support route: https://www.finfold.app/extension/support
- [ ] Deploy and live-verify the updated extension disclosure: https://www.finfold.app/privacy
- [x] English and Simplified Chinese names/descriptions.

Screenshots and promotional art must be regenerated after any visible UI change. Do not use a mock result, fake account balance, or a development build in store media.
